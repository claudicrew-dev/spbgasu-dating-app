СПБГАСУ Знакомства — Telegram Mini App для @gasulvbot, v4

Откройте ЗАПУСК_В_TELEGRAM.md: в нём пошаговый запуск на VPS, настройка бота, проверки и резервное копирование.

В архиве нет токена, пользовательских данных и тестовых анкет. Создайте .env из .env.example на сервере.

Стек: Node.js 24, встроенный SQLite (WAL), HTTP API, серверные события, Telegram webhook, Docker Compose и Caddy для HTTPS.
База и фото сохраняются в постоянном томе; настроено ежедневное резервное копирование последних 7 копий.

Функции: вход по подписанным данным Telegram, анкета, фото, свайпы, лайки, взаимная симпатия, чаты, подписки, уведомления, жалобы, блокировка, удаление аккаунта, модерация.
Счётчики и действия других людей рассчитываются на сервере. Локальные данные предыдущего макета не используются.

Пока сервер не размещён и бот не настроен, приложение в Telegram не запущено.
Обычное открытие index.html больше не запускает локальный прототип: рабочему приложению нужны сервер и Telegram.

Нельзя удалять Docker-том базы: docker compose down -v уничтожает данные.

Для разработчика:
  npm test
  npm start                    (локально: .env, APP_ENV=development, PUBLIC_URL=http://localhost:3000, DB_PATH=data/app.sqlite)
  npm run telegram:setup       (настроить меню и webhook после размещения)
  npm run telegram:check       (проверить подключение бота)
  npm run backup

Автоматические тесты используют временные изолированные базы и не добавляют анкеты в рабочее приложение.
